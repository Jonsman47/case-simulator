# Career Upgrade System

This document is the authoritative human-readable companion to the typed registry in `src/career/careerUpgrades.ts`. Save schema v37 stores only stable upgrade IDs, levels, purchase timestamps, and one-time migration metadata; definitions and unlock state remain derived.

## Architecture

The system contains exactly **95 run-based nodes**: 18 Case Opening, 22 Trading, 16 Collecting, 18 Trade-Ups, and 21 Business. Purchases use cash plus bounded noncash migration credit. Career XP is never spent.

`CashCost(L) = round(baseCash × 1.72^L × rankMultiplier, 2)`, where `L` is the currently owned level.

Reducer validation is authoritative. It checks the stable ID, Career level, specialization XP, prerequisites, affordability, and maximum level. Every purchased level changes the registry effect. Default branch-activity gates are 1,000 XP at Career level 15, 5,000 at level 35, 12,500 at level 55, and 25,000 at level 75. All active information tools are surfaced in the Career specialization toolkit; mechanical families are also read by their named gameplay consumer.

## Effect composition and safety

- Official case rarity, float, wear, and Pattern generation are never modified.
- Legacy Skill Tree and run-upgrade helpers are neutral and their routes/actions are retired.
- Additive capacities are summed by typed effect key. Discounts/speed reductions have explicit helper caps: training 15%, payroll 10%, Business interval reduction 15%, seller-fee reduction 2.5%, and animation acceleration 30%.
- Marketplace sales retain a minimum 2.5% seller fee. Employees retain budgets, payroll, reserves, capacity, confirmation thresholds, and exact-once request IDs.
- Research nodes reveal or organize existing deterministic information; they do not predict drops, create supply, change seller reservation prices, or guarantee profit.
- Every node resets on Prestige. Migration credit, lifetime Career XP, achievements, and historic records do not reset.

## Legacy conversion

The v36→v37 migration records legacy Skill Points, Upgrade Points, learned Skill Tree nodes, and eligible old run-upgrade levels. It awards one bounded noncash Career Upgrade credit:

`min($75,000, SkillPoints×$500 + UpgradePoints×$1,000 + LearnedSkills×$250 + EligibleUpgradeLevels×$750)`.

Prompt 3's Module Bay/Business conversion is excluded to prevent double compensation. The marker is deterministic and idempotent; reload and Prestige cannot regenerate credit. Old fields remain serialized for history/compatibility but have no gameplay authority and cannot be purchased.
